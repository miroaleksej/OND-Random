# Security Policy

## Scope
OND Random is a research-grade RNG and analysis toolkit. The security scope includes:

- `ONDMaxRNG` extractor implementation
- Raw OND metrics and protocol observations
- Build and release pipeline

## Reporting
If you discover a security issue, please open a private report by emailing:

- **security@example.com** (replace with your address)

Include:
- A clear description of the issue
- Steps to reproduce
- Impact assessment

We aim to respond within 7 days.

## Supported Versions
Only the latest release on the `main` branch is supported.
